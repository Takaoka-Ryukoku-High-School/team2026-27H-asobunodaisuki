# 今日の段取り

Python と Flet で作った、ブラウザで使える月間予定表です。予定の追加、完了切替、削除、状態別の絞り込みに対応しています。同じアプリURLを開いている人の予定は共有され、変更は接続中の画面に反映されます。データはサーバーのホームディレクトリにあるSQLiteデータベースへ保存されます。

アカウントや閲覧・編集権限はありません。URLを知っている人は予定を見たり変更したりできるため、信頼できる人とのみ共有してください。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。
